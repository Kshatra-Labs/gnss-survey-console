GNSS Survey Console

Base and Rover both plug into USB ports on real devices and run entirely in the browser.
A single GPS is accurate to a few metres. Two GPS units working together as RTK - one fixed, one carried around - are accurate to a couple of centimetres. That's what this page runs:
Base
Plug this receiver into a USB port on whatever device is staying put, connect it below, and leave it running. It works out its own position precisely, then uploads corrections to the cloud relay.
Rover
Plug this one into a USB port on whatever device you're carrying around, connect it, and pull corrections from the same relay channel to get a centimetre-accurate reading of wherever it currently is.
The relay only forwards bytes - it has no USB/GPS access of its own, so all the actual GNSS work happens on whichever device has a receiver plugged in, here or in the Android app. Requires Chrome or Edge (Web Serial API) - not Firefox or Safari.
