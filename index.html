A single GPS is accurate to a few metres. Two GPS units working together as RTK - one fixed, one carried around - are accurate to a couple of centimetres. That's what this page runs:
Base
Plug this receiver in at the GCS and leave it there. It works out its own position very precisely, then broadcasts a correction feed. You configure it once per survey session and don't move it.
Rover
Plug this receiver into this device (phone/laptop USB port) and carry it to each point you're surveying. The browser talks to it directly - no server needed for this part.

Backend server

Only needed to control the Base receiver remotely, and to fetch its corrections. Auto-filled with this project's known address - change it only if your base runs somewhere else.
